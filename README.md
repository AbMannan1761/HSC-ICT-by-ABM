# HSC ICT Interactive Web App & Study Platform

An interactive online reader, study guide, and practice portal for the HSC Information and Communication Technology (ICT) curriculum.

## Features
- 📚 **Complete NCTB Chapters**: Interactive chapter-by-chapter reading experience.
- 💡 **Practice & Code Board**: Integrated code practice and review.
- 🔍 **Real-time Search**: Quick topic lookup and fast navigation.
- 🎨 **Modern Dark UI**: Responsive design with clean typography and dark theme.

## Getting Started Locally
You can open `index.html` directly in any modern browser, or run a local static server:

```bash
# Using Python
python -m http.server 8080
```
Then navigate to `http://localhost:8080/index.html`.

## Deployment
This static web application can be deployed instantly to **GitHub Pages**, **Vercel**, or **Netlify**.
